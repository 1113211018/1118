🚀 一鍵發布到 GitHub Pages 免費托管

本遊戲已將所有程序化材質、Canvas 物理引擎與 Web Audio ASMR 音效整合於單一 HTML 檔案中，直接上傳 GitHub 即可遊玩：

  1. 登入 GitHub.com，點擊右上角 + → New repository 建立新儲存庫（例如 jade-live-simulator）。
  2. 點擊下方按鈕複製完整原始碼，在儲存庫中點選 Add file → Create new file，檔名輸入 index.html 並貼上儲存。
  3. 前往儲存庫的 Settings → Pages，在 Branch 選擇 main 並按下 Save，約 1 分鐘後即可獲得您的專屬遊戲連結！
