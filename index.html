🚀 一鍵發布至 GitHub Pages

本遊戲已採用零依賴單一 HTML 檔案架構，無需安裝任何套件即可直接託管在 GitHub：

  1. 登入你的 GitHub 帳號，點擊右上角 + 建立新的儲存庫（Repository，例如命名為 jade-blindbox）。
  2. 點擊 uploading an existing file，將此網頁存成 index.html 並上傳至儲存庫。
  3. 進入儲存庫的 Settings（設定） → 左側選單點擊 Pages。
  4. 在 Branch 下拉選單選擇 main 資料夾 / (root)，點擊 Save。
  5. 等待約 1 分鐘，GitHub 即會產生專屬網址，隨時在手機或電腦上分享遊玩！
