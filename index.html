🚀 如何部署到 GitHub Pages？

本遊戲採用單一 HTML 檔案架構，無需任何後端伺服器或建置工具，只需 3 步驟即可免費發布到 GitHub：

  1. 前往 GitHub.com 建立一個新的公開儲存庫（Repository），例如命名為 jade-cutting-game。
  2. 點擊下方按鈕複製完整原始碼，在儲存庫中新增檔案 index.html 並貼上儲存（或直接將本檔案上傳）。
  3. 進入儲存庫的 Settings → Pages，在 Branch 選擇 main 並按下 Save，等待約 1 分鐘即可獲得專屬遊戲網址！
